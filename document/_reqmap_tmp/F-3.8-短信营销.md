# 3.8 短信营销 —— 需求实现点清单（竞品手册对照）

> 手册行号：L1219-1280 ｜ 需求点数量：10 ｜ 覆盖统计：已覆盖5 / 部分3 / 未覆盖0 / 无依据2

**章节引言（L1221）**：实现标准化短信设置，定时、定点发送包括预约提醒、生日提醒、诊疗提醒等在内的短信推送，方便用户更快地了解医院及宠物的诊疗信息。
**映射结论摘要**：毛线球以「消息与客户触达」模块整体承接（消息模板 + 发送记录 + Provider 适配 + 营销 Campaign 触发），渠道为短信/邮件/微信/企业微信多渠道适配（SMS 为真实 Provider，WeChat 为占位），「短信条数购买/余量」因商业模式差异无对应依据。详见各需求点。
