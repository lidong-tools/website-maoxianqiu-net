# 宠物医院管理系统 · 行业需求对标与遗漏分析

> 分析时间：2026-08-07
> 目的：以行业（中国 + 全球 + 法规）需求基线，对照毛线球 `document/stage-0*` 三阶段需求文档，找出需求遗漏。
> 方法：公开资料调研（CN 通用功能清单、竞品 小暖/微宠医/蘑菇宠医、全球 PMS AVImark/Cornerstone/ezyVet/Neo/Provet Cloud/Shepherd/Digitail/SmartFlow/Covetrus、法规《动物诊疗机构管理办法》+ 病历管理规范 + 四川省 2025-08 通知 + 农业农村部 734 号公告）+ 与毛线球需求文档比对。

---

## 1. 行业需求基线（四类来源）

### 1.1 通用业务功能（CN 通用清单）
患者/宠物电子档案、预约（在线/提醒/爽约）、诊疗（诊断报告/处方/治疗计划）、财务管理（收费/发票/对账）、员工（排班/考勤/绩效）、设备管理（维护/耗材/借用）、库存（药品/耗材预警）、客户服务（咨询/投诉/回访）、统计报表、美容、手术、职业培训、采购、销售、线上问诊、私域营销。

### 1.2 国内竞品能力
- **小暖**：CRM、电子病历、化验室（**设备连接，已连 2300 台**）、进销存、线上问诊+电子处方、数据报表、**微信会员卡/积分商城/优惠券/处方粮复购/健康提醒**、**中心药房+药品牌照**、**宠物保险（人保/众安）**、集团多门店业绩、院长移动推送。
- **微宠医**：处方粮预定、在线预约/快速问诊、宠物健康知识提醒、医院用户互联。
- **蘑菇宠医**：在线问诊、**处方双重审核（循证、防重复/配伍禁忌/超疗程）**、线上购药（兽药经营许可）。

### 1.3 全球 PMS 能力
SOAP 病历、estimate/charge capture 自动计费防漏、LIS 化验设备直连（IDEXX VetConnect）、影像集成、宠主端 App/客户门户（Digitail/Shepherd）、telemedicine、AI 语音转 SOAP（Woovet/Shepherd）、ICU 数字白板/实时体征（SmartFlow）、多门店、在线药房、合规（RBAC/审计/SOC2/GDPR/数据迁移）。

### 1.4 法规强制项（合规红线）
病历保存 ≥3 年、电子病历操作追溯 + 可靠电子签名、处方规范 + **执业兽医师签名留样/电子签章备案后方可开方**、**毒麻/精神/毒性药品专项管控**、**诊疗废弃物无害化处置**、**疫情/染疫上报 + 隔离消毒**、执业兽医备案、诊疗许可证公示/变更/分支另办、年度报告、兼营美容寄养独立区域。

## 2. 毛线球覆盖度与遗漏矩阵

判定：🔴 合规遗漏（法规强制）｜🟠 行业标配缺口（竞争力/需决策）｜🟡 增强缺口（可排 P1/P2）｜🟢 小遗漏｜✅ 已覆盖/有意排除

### 2.1 合规红线组（最高优先级）

| 功能 | 行业/法规依据 | 毛线球状态 | 判定 |
|---|---|---|---|
| 诊疗废弃物处置记录（交接/无害化） | 诊疗机构管理办法 §26、医疗废物管理条例、四川通知 | **完全未覆盖** | 🔴 遗漏 |
| 疫情/染疫上报 + 隔离消毒措施记录 | 诊疗机构管理办法 §25（强制、不得瞒报） | 仅宠物"传染"风险标签（PRD §294），**无上报模块** | 🔴 遗漏 |
| 毒麻/精神/毒性药品专项管控（采购/双人双锁/空瓶回收） | 兽药管理条例、734 号公告 | 仅提"处方保存 5 年"（PRD §759），**无管控流** | 🔴 遗漏 |
| 签名留样 / 电子签章备案（备案单位留样后方可开方） | 四川通知、734 号公告 | 仅"执业兽医备案门禁"，**未建模留样/签章备案** | 🟠 缺口 |
| 动物诊疗许可证生命周期（公示/变更/分支另办） | 诊疗机构管理办法 §13-§17 | 未覆盖（多租户偏技术，无许可证维度） | 🟠 缺口 |
| 年度报告（年度活动报告） | 诊疗机构管理办法、四川通知 | 未覆盖 | 🟠 缺口 |
| 检验/处方双重审核（循证、防重复/配伍禁忌/超疗程） | 蘑菇宠医实践、用药安全 | 检验未强制双人；处方无审核环节 | 🟠 缺口 |
| 病历保存 ≥3 年 / 可靠电子签名 | 法规 | 保存期已覆盖（§17）；电子签名**延后**（ADR-MED-002） | 🟡 已知 |

### 2.2 核心临床组

| 功能 | 行业普遍性 | 毛线球状态 | 判定 |
|---|---|---|---|
| 手术管理独立模块（麻醉记录/手术同意书/术后护理） | CN 通用清单 | 无独立模块（仅处置/处方） | 🟡 遗漏 |

| 收费自动捕获防漏费 | 全球 PMS 卖点 | 仅处方发药联动收费 | 🟡 部分 |

| 功能 | 行业普遍性 | 毛线球状态 | 判定 |
|---|---|---|---|

| 功能 | 行业普遍性 | 毛线球状态 | 判定 |

## 3. 分层结论

### 🔴 必须补（合规红线，法规强制，验收/上线风险）
诊疗废弃物处置记录、疫情/染疫上报、毒麻品专项管控流、签名留样/电子签章备案、诊疗许可证生命周期、年度报告、检验/处方双重审核。
→ 建议将阶段3 PRD §17 合规专章**逐条对齐**《动物诊疗机构管理办法》+ 四川省 2025-08 通知 + 734 号公告，形成"法规条款 → 系统能力"映射表，作为验收基线。

### 🟠 需产品决策的竞争力/行业标配缺口
宠主端 App/门户、在线问诊生态对接、LIS 设备直连、私域营销引擎、宠物保险对接、中心药房。
→ 这些部分已被阶段3 明确"有意排除"（在线问诊、保险直连、AI 自动诊断），但市场视其为标配；建议在 PRD 显式标注"生态对接预留"而非完全沉默，避免被误判为能力缺失。

### 🟡 运营增强（排 P1/P2）
排班考勤绩效、设备全生命周期、手术独立模块、ICU 白板、收费自动捕获、投诉管理、培训中心、院长移动看板、影像报告集成。

### ✅ 已覆盖 / 有意排除（非遗漏）
多租户连锁、EMR/SOAP、处方发药、FEFO 库存、危急值、住院押金/换房、日结对账、审计/权限/RLS、DICOM PACS/设备直控/AI 自动诊断（有意排除）、美容（已静默降级，见《三阶段需求遗漏与一致性审查》需决策）。

## 4. 关键证据锚点

- **法规**：《动物诊疗机构管理办法》§22（病历≥3年）、§23（处方笺规范）、§25（疫情上报）、§26（废弃物）；《动物诊疗病历管理规范》（电子签名同等效力、操作追溯）；四川省农业农村厅 2025-08 通知（规范病历处方/用药/废弃物/年度报告/疫情）；农业农村部公告第 734 号（兽医处方格式、毒麻品）。
- **竞品**：小暖（CRM/化验室设备连接/线上问诊/微信营销/中心药房/保险）、微宠医（处方粮/在线问诊）、蘑菇宠医（在线问诊双重审核/线上购药）。
- **全球**：IDEXX VetConnect（LIS 集成）、SmartFlow（ICU 数字白板）、Shepherd/Digitail（client portal + AI）、ezyVet（100+ 集成）。
- **毛线球**：阶段3 PRD §759"兽用麻醉药品、精神药品、毒性药品处方至少保存 5 年"（仅保存期，无管控流）；§294"传染/咬人/麻醉等风险标签"（无疫情上报模块）；§17 合规专章未覆盖废弃物/疫情/许可证/年度报告/双重审核。
