# 4. Phase 1：Staging 环境准备

## Task 1.1 建立 Staging

目标：

建立真实验证环境。

执行：

1.  记录 Git 版本
2.  创建数据库
3.  执行全部 migration
4.  初始化测试数据
5.  验证系统启动

输出：

    staging-init-report.md

验收：

-   migration 全部成功
-   无人工修复
-   系统正常启动

# 6. Phase 3：权限安全验证

目标：

验证 SaaS 多租户隔离。

测试角色：

  角色         范围
  ------------ ----------
  系统管理员   全部
  租户管理员   Tenant
  门店管理员   Store
  医生         医疗
  护士         执行
  前台         预约收费

必须验证：

## Tenant 隔离

用户 A：

tenant=A

访问：

tenant=B

结果：

403。

------------------------------------------------------------------------

## Store 隔离

门店 A 员工不能访问门店 B 数据。

输出：

    permission-security-report.md

------------------------------------------------------------------------

# 7. Phase 4：医疗业务闭环

核心流程：

    客户
    ↓
    宠物
    ↓
    预约
    ↓
    签到
    ↓
    候诊
    ↓
    接诊
    ↓
    病历
    ↓
    医嘱
    ↓
    处方
    ↓
    收费
    ↓
    支付
    ↓
    审计

必须验证：

## 病历

检查：

-   创建
-   签署
-   归档
-   修改申请
-   审计

要求：

签署后禁止直接修改。

------------------------------------------------------------------------

## 处方

检查：

-   医生身份
-   签名
-   有效期
-   状态流转

输出：

    medical-loop-test-report.md

------------------------------------------------------------------------

# 8. Phase 5：库存一致性验证

流程：

    采购
    ↓
    入库
    ↓
    库存
    ↓
    处方占用
    ↓
    发药
    ↓
    扣减
    ↓
    取消释放

重点：

并发扣减测试。

要求：

-   不允许库存负数
-   不允许重复扣减

输出：

    inventory-consistency-report.md
