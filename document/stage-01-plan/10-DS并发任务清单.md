## 任务门禁

任务完成必须同时满足：

- 正确目录；
- 无未说明 `any`；
- migration 可重复应用；
- RLS 测试；
- API 契约；
- UI 状态完整；
- build/lint；
- Preview；
- 截图；
- 文档更新。
